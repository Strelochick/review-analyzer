# ReviewLab — ML-продукт для анализа отзывов

Практическая работа №10 по дисциплине «Технология разработки и защиты баз данных».

Продукт анализирует отзывы покупателей интернет-магазина электроники: определяет тональность отзыва,
маскирует персональные данные, прогнозирует количество отзывов, строит персональные рекомендации
и показывает аналитику в веб-интерфейсе.

## Датасет
`reviews_dataset.csv` — 600 отзывов, 10 товаров, 90 пользователей, период июль–сентябрь 2026.
Поля: `id, text, rating, product, date, user_id, user_name, phone`.
Датасет создан скриптом `generate_dataset.py` (у каждой группы пользователей свои предпочтения по категориям товаров).

## Структура проекта
| Файл | Назначение |
|---|---|
| `generate_dataset.py` | генерация собственного датасета |
| `ml.py` | основные функции: загрузка данных, `predict_sentiment`, `top_products_by_positive`, `top_negative_words`, маскировка, прогноз, рекомендации (user-based CF) |
| `main.py` | код с лекции под свой датасет + формирование `student_report.png` |
| `compare_models.py` | сравнение LogisticRegression, RandomForest, XGBoost → `models_metrics.csv` |
| `charts.py` | графики: распределение оценок, динамика по дням, облако слов |
| `db.py` | хранение отзывов в SQLite (`reviews.db`) |
| `app.py`, `templates/` | веб-интерфейс на Flask |

## Запуск
```
pip install -r requirements.txt
python main.py             # отчёт student_report.png
python compare_models.py   # таблица метрик моделей
python app.py              # веб-интерфейс http://127.0.0.1:5000
```

## Модели
* В `compare_models.py` три модели сравниваются на TF-IDF по словам и парам слов (LogisticRegression лучшая, F1 = 0.992).
* В веб-приложении и `main.py` используется LogisticRegression на TF-IDF по символьным n-граммам (2–4 символа)
  с `class_weight='balanced'` — так модель лучше понимает разные формы слов в новых отзывах.

## Веб-интерфейс
* **Главная** — форма отзыва (текст + оценка 1–5) с предсказанием тональности, сохранение в SQLite,
  рекомендации для текущего пользователя, графики: распределение оценок, облако слов, динамика по дням.
* **Статистика по товарам** — средний рейтинг, количество отзывов, доля позитива.
* **Сравнение моделей** — таблица Accuracy / Precision / Recall / F1 и качество рекомендаций.

Пользователь получает уникальный ID при первом входе, ID хранится в cookies.
